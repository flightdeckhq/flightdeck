  Database  {{ if eq (include "flightdeck.database" .) "sqlite" }}SQLite, on each pod's own volume{{ else if .Values.postgres.externalUrl }}Postgres (postgres.externalUrl){{ else }}Postgres (the chart's own StatefulSet){{ end }}

Wait for it:

  kubectl -n {{ .Release.Namespace }} rollout status statefulset/{{ $name }}

The dashboard{{ if .Values.ingress.enabled }} is at http{{ if .Values.ingress.tls }}s{{ end }}://{{ .Values.ingress.host }}. Without the Ingress:{{ else }}:{{ end }}

  kubectl -n {{ .Release.Namespace }} port-forward svc/{{ $name }} 4000:{{ .Values.flightdeck.service.port }}
  # then open http://localhost:4000

The access token for the sensor and the plugin. Each pod mints one on
its first start and prints it once in its start-up block; the dashboard
loads it from /runtime-config.json, and the Settings page mints more:

  kubectl -n {{ .Release.Namespace }} logs {{ $name }}-0 | grep Token
  curl -s http://localhost:4000/runtime-config.json     # through the port-forward

Whoever can reach the Service can read that token: expose it only
behind an Ingress or a network that authenticates.
